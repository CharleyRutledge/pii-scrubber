# Third-party reference material

`presidio_templates_reference.txt` is copied from Microsoft's
[presidio-research](https://github.com/microsoft/presidio-research)
project (`presidio_evaluator/data_generator/raw_data/templates.txt`),
licensed under MIT. It contains sentence *templates* with placeholder
tokens like `{{credit_card_number}}` and `{{person}}`, not any real data.

Used here as inspiration for `tools/audit_corpus.py` test cases covering
realistic customer-support phrasing, filled in with our own invented
values.
